**If a human eye can read the image, Tujie can recognize it.**

Tujie is an AI image recognition platform for developers and businesses. It does OCR text recognition, object localization with coordinate-level precision, and GIF / dynamic image understanding — and it recognizes every kind of CAPTCHA: click-select, letters, numbers, Q&A, even brain teasers.

| Capability | What it does |
| --- | --- |
| 📝 OCR text recognition | Printed / handwritten text, tables, receipts, multilingual — image in, plain text out |
| 🎯 Object localization | Bounding boxes, coordinate-level results, multi-target detection in one call |
| 🎞️ Dynamic image understanding | Native GIF / animated image / video-frame support |

## Every kind of CAPTCHA — the core scenario

Click-select, letters, numbers, Q&A, brain teasers… If a human can read it, Tujie can recognize it:

- 🖱️ Click-select CAPTCHA: click characters / click images / ordered multi-click
- 🔤 Letter CAPTCHA: letters, case and special characters
- 🔢 Numeric CAPTCHA: pure digits and multi-digit numbers
- 🔡 Alphanumeric mix: any combination
- ❓ Q&A CAPTCHA: math questions / general-knowledge Q&A
- 🧠 Brain teasers: pattern puzzles / visual reasoning

💡 Great for automation testing, bulk data entry, passing logins, bot verification — everything that needs to "read the image".

```bash
